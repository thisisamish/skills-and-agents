# Triggering queries

Ask the agent each query with all career skills installed, and record which skill loads. Target: at least 90% correct.

## capture-work-experience

- Save this experience: I reduced our API latency by adding Redis caching.
- Make a resume bullet out of this.
- Can you turn what I did this sprint into STAR bullets? (followed by a pasted paragraph)
- Here's what I worked on last quarter: … (a pasted work description)
- I got the metric for the caching work: p95 went from 900 ms to 300 ms.
- Help me write an impact bullet for the migration I led.
- I spent this week helping two new joiners get their environments working; add that to my record.
- Log this for later: I helped the testing team reproduce a crash today.
- Process my work log.
- I want to list everything I've done at this job and build my record from scratch.

## maintain-career-record

- Add my B.Tech degree and CGPA to my career record.
- Update my LinkedIn and GitHub links.
- I joined Example Corp as a Systems Engineer in July 2023; add that.
- Review my career record and tell me what's missing.
- Migrate my old CMD.md to the new format.
- Add Kubernetes to my skills.

## setup-career-skills

- Set up the career skills in this repo.
- Initialise career tracking here.
- The career skills say my Python environment is missing.

## Should trigger none of them

- Write a Python function to parse this CSV.
