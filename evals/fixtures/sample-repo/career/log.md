# Work log

Quick notes on work as it happens, so nothing is forgotten before it's captured. It matters most for work that's on no board: help you gave teammates, things you started yourself, and results that arrived after the work was done.

One line per entry, newest at the bottom:

    - [ ] 2025-03-14 · asked by new joiner · explained the build setup and fixed their environment · they pushed their first change the same day
    - [ ] 2025-03-20 · self · wrote a setup guide for the module after the third person asked · two new joiners used it instead of asking

Fields: date · origin (`assigned`, `self`, or `asked by <role>`) · what you did · what happened.

- Use roles, not names ("new joiner", "team lead"). No code, internal links or client names.
- Rough is fine. Details get filled in when an entry is captured.
- When an entry has been captured, the agent ticks it and adds the accomplishment ID: `- [x] … → <id>`. Several entries can feed one accomplishment. Never delete entries.
