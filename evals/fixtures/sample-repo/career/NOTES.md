# Career Evidence & Audit Log

Append-only record of what the user said and what changed in the career record. Never edit or delete an entry; correct by appending a new one.

Do not store source code, credentials, secrets, internal URLs, customer names, screenshots, proprietary technical details or other confidential content.

Entries look like this:

    ## 2025-03-14T10:02:00+05:30

    ### Source
    User conversation

    ### New Information
    - ...

    ### Record Changes
    - Added accomplishment <id>: ...

    ### Evidence Status
    - Confirmed by user / inferred from user statement / requires verification
