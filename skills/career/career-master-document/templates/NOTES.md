# Career Evidence & Audit Log

This file is the append-only reference and audit trail for the Career Master Document.

Record user-supplied career facts, corrections, accomplishments, metrics, goals, and changes made to `CMD.md`. Do not store source code, credentials, secrets, internal URLs, customer information, screenshots, proprietary technical details, or confidential content.

Add entries using the format in `SKILL.md`. Do not delete or rewrite historical entries.
